# FORGE – RAPTOR

**RAPTOR: Resilient Autonomous Navigation and Persistent Target Observation in Contested Indoor Environments**
METU EE493/EE494 Capstone Design Project, 2026–2027 · Design Studio Section 2

An autonomous ground robot that localizes itself indoors using four UWB anchors, an IMU and a camera, visits waypoints, detects and follows a moving target, and keeps operating safely when its sensors degrade.
